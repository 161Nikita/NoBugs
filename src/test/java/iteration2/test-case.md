## 1. Депозит денег пользователем (Пополнение счета)
**По ТЗ:** Сумма пополнения должна быть положительной, максимум 5000 за один раз. Нельзя делать депозит на чужой или несуществующий счет.

### Позитивный кейс: Успешное пополнение собственного активного счета (целое число)
*   **Предусловия:** Авторизован пользователь с ролью `USER`. В базе данных существует открытый счет с ID `5`, принадлежащий этому пользователю.
*   **Метод и URL:** `POST /api/v1/accounts/deposit`
*   **Тело запроса (JSON):**
    ```json
    {
      "accountId": 5,
      "amount": 2000.00
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `200 OK`. Баланс счета увеличился на 2000.00.

### Позитивный кейс: Успешное пополнение счета на дробную сумму (с копейками)
*   **Предусловия:** Авторизован пользователь с ролью `USER`. Существует счет с ID `5`.
*   **Метод и URL:** `POST /api/v1/accounts/deposit`
*   **Тело запроса (JSON):**
    ```json
    {
      "accountId": 5,
      "amount": 150.55
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `200 OK`. Баланс счета успешно увеличен на дробную сумму.

### Негативный кейс: Попытка пополнения на сумму, превышающую лимит (> 5000)
*   **Предусловия:** Авторизован пользователь с ролью `USER`. Существует счет с ID `5`.
*   **Метод и URL:** `POST /api/v1/accounts/deposit`
*   **Тело запроса (JSON):**
    ```json
    {
      "accountId": 5,
      "amount": 5000.01
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `400 Bad Request`. Сообщение об ошибке валидации лимита.

### Негативный кейс: Попытка пополнения чужого или несуществующего счета
*   **Предусловия:** Авторизован пользователь с ролью `USER`, но счет с ID `410` ему не принадлежит или не существует в системе.
*   **Метод и URL:** `POST /api/v1/accounts/deposit`
*   **Тело запроса (JSON):**
    ```json
    {
      "accountId": 410,
      "amount": 0.1000
    }
    ```
*   **Ожидаемый результат** Бэк возвращает статус `403 Forbidden` и JSON с ошибкой `"Unauthorized access to account"`.

## 2. Перевод денег с одного аккаунта на другой
**По ТЗ:** Максимальная сумма перевода составляет 10000. Сумма должна быть положительной и не превышать текущий баланс отправителя. Переводы возможны как между своими счетами, так и на счета чужих пользователей.

### Позитивный кейс: Успешный перевод денег между своими счетами
*   **Предусловия:** Авторизован пользователь с ролью `USER`. На его счету-отправителе `4` баланс равен или больше суммы перевода. Второй счет `5` также принадлежит текущему пользователю.
*   **Метод и URL:** `POST /api/v1/accounts/transfer`
*   **Тело запроса (JSON):**
    ```json
    {
      "senderAccountId": 4,
      "receiverAccountId": 5,
      "amount": 500.00
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `200 OK` и тело ответа с сообщением `"Transfer successful"`. С баланса счета `4` списано 500, на счет `5` зачислено 500.

### Позитивный кейс: Успешный перевод на счет чужого пользователя (стороннему клиенту)
*   **Предусловия:** Авторизован пользователь с ролью `USER`. На его счету-отправителе `4` достаточно средств. Счет-получатель с ID `12` принадлежит другому зарегистрированному пользователю банка.
*   **Метод и URL:** `POST /api/v1/accounts/transfer`
*   **Тело запроса (JSON):**
    ```json
    {
      "senderAccountId": 4,
      "receiverAccountId": 12,
      "amount": 1000.00
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `200 OK` и сообщение `"Transfer successful"`. Средства успешно переведены стороннему клиенту.

### Позитивный кейс: Успешный перевод суммы с копейками (дробное число)
*   **Предусловия:** Авторизован пользователь с ролью `USER`. На его счету-отправителе `4` достаточно средств. Существует счет-получатель `5`.
*   **Метод и URL:** `POST /api/v1/accounts/transfer`
*   **Тело запроса (JSON):**
    ```json
    {
      "senderAccountId": 4,
      "receiverAccountId": 5,
      "amount": 1000.01
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `200 OK` и JSON с подтверждением перевода `"message": "Transfer successful"`.

### Негативный кейс: Попытка перевода суммы, превышающей баланс отправителя
*   **Предусловия:** Авторизован пользователь с ролью `USER`. На его счету-отправителе `4` недостаточно средств для проведения операции.
*   **Метод и URL:** `POST /api/v1/accounts/transfer`
*   **Тело запроса (JSON):**
    ```json
    {
      "senderAccountId": 4,
      "receiverAccountId": 5,
      "amount": 5000.00
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `400 Bad Request` и JSON с ошибкой `"Invalid transfer: insufficient funds or invalid accounts"`.

### Негативный кейс: Попытка перевода суммы, превышающей максимальный лимит (> 10000)
*   **Предусловия:** Авторизован пользователь с ролью `USER`. На его счету-отправителе достаточно средств (например, 20000.00).
*   **Метод и URL:** `POST /api/v1/accounts/transfer`
*   **Тело запроса (JSON):**
    ```json
    {
      "senderAccountId": 4,
      "receiverAccountId": 5,
      "amount": 10000.01
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `400 Bad Request`. Возникает ошибка валидации (Сумма превышает лимит 10000).

## 3. Изменение имени пользователя в профиле (name)
**По ТЗ:** Имя должно состоять строго из двух слов (Имя и Фамилия), содержать только буквенные символы и разделяться одним пробелом.

### Позитивный кейс: Успешное изменение имени на валидный формат
*   **Предусловия:** Авторизован пользователь с ролью `USER`.
*   **Метод и URL:** `PUT /api/v1/customer/profile`
*   **Тело запроса (JSON):**
    ```json
    {
      "name": "Nikita Krapivin"
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `200 OK`. В профиле пользователя значение поля `"name"` успешно обновлено на `"Nikita Krapivin"`.

### Негативный кейс: Попытка установить имя, состоящее только из одного слова
*   **Предусловия:** Авторизован пользователь с ролью `USER`.
*   **Метод и URL:** `PUT /api/v1/customer/profile`
*   **Тело запроса (JSON):**
    ```json
    {
      "name": "Nikita"
    }
    ```
*   **Ожидаемый результат:** Бэк возвращает статус `400 Bad Request`. Возникает ошибка валидации формата имени.
